Controle remoto

Opere a mesa pelo navegador de um celular ou tablet na mesma rede Wi-Fi (segunda tela). Desligado por padrão e sempre desligado ao abrir o programa.

Atenção: a conexão é HTTP puro, sem criptografia (TLS) — use só em rede de confiança. Cada aparelho recebe uma chave própria que expira; o PIN vale para um único pareamento. Redes de convidados/“isolamento de clientes” bloqueiam o acesso. Na primeira vez o Windows pede para liberar o firewall: permita em redes privadas.
